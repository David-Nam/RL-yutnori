# 전체 뒷도 50M 장기 학습 결과 분석

작성일: 2026-06-11

## 1. 결론

전체 뒷도 규칙 `full_backdo_v1`로 학습한 MaskablePPO 3개 시드는 모두
50M 학습과 공식 5,000게임 평가를 정상 완료했다.

핵심 결론은 다음과 같다.

- 공식 평가 합산 승률은 `60.72%` (`9,108/15,000`)다.
- 공식 평가에서 세 모델 모두 사전에 정한 `60%` point threshold를 통과했다.
- 공식 평가 합산 95% Wilson 구간은 `59.94%-61.50%`로, 하한은 60%보다
  `0.06%p` 낮다. 따라서 공식 평가만으로 "모집단 승률이 60%를 확실히
  넘는다"고 단정하기에는 경계선이다.
- 사용하지 않은 별도 홀드아웃에서 최종 50M 합산 승률은 `60.79%`
  (`9,118/15,000`), 95% 구간은 `60.00%-61.57%`였다.
- 같은 홀드아웃에서 40M 체크포인트는 `60.21%`였고 최종 50M이
  `+0.58%p` 높았다. 차이는 작지만 50M을 버릴 근거는 없다.
- 대표 후보는 `seed 2` 최종 모델이다. 서로 겹치지 않는 세 평가 구간
  15,000게임에서 `61.25%` (`9,187/15,000`), 95% 구간
  `60.46%-62.02%`를 기록했다.
- 모든 공식·추가 평가에서 illegal action과 evaluation error는 `0`이었다.

따라서 현재 산출물 중에서는 `seed 2 / final 50M`을 대표 모델로 선정하는
것이 가장 타당하다.

## 4. 학습 결과

| 시드 | 완료 게임 | 학습 중 승률 | 평균 decision | 평균 learner step | 평균 turn |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 0 | 1,933,301 | 56.52% | 50.54 | 25.86 | 33.23 |
| 1 | 1,925,730 | 56.55% | 50.67 | 25.97 | 33.34 |
| 2 | 1,942,222 | 57.00% | 50.14 | 25.75 | 33.24 |
| 합산 | 5,801,253 | 56.69% | - | - | - |

학습 중 승률은 stochastic action을 사용하며 각 구간에서 변화하는 정책 전체를
평균한 값이다. 최종 deterministic checkpoint 평가와 직접 같은 수치로 보면
안 된다.

### 4.1 수렴 곡선

아래는 각 5M 구간의 세 시드 단순 평균이다.

| 구간 | 학습 승률 | 평균 decision |
| --- | ---: | ---: |
| 0-5M | 44.68% | 52.86 |
| 5-10M | 54.57% | 51.60 |
| 10-15M | 56.52% | 50.91 |
| 15-20M | 57.52% | 50.50 |
| 20-25M | 57.89% | 50.17 |
| 25-30M | 58.38% | 50.02 |
| 30-35M | 58.79% | 49.85 |
| 35-40M | 59.12% | 49.73 |
| 40-45M | 59.38% | 49.53 |
| 45-50M | 59.60% | 49.42 |

0-5M에서 5-10M으로 갈 때 약 `+9.89%p`가 개선돼 초기 학습 효과가 가장
컸다. 이후 개선 속도는 느려졌지만 50M까지 전체 평균은 계속 상승했다.
동시에 평균 decision은 `52.86 -> 49.42`로 약 `6.5%` 감소했다.

시드별 마지막 구간은 seed 0이 `59.49%`, seed 1이 `59.36%`, seed 2가
`59.95%`다. seed 0은 40-45M 대비 거의 정체됐고 seed 1·2는 계속 상승했다.
뚜렷한 전 시드 공통 붕괴는 관찰되지 않았다.

게임 길이 분포도 안정적이다. 전체 decision의 중앙값은 49-50, 95백분위는
74-75, 99백분위는 86-87이었다.

## 5. 공식 평가

평가 조건은 base seed `100000-102499`의 각 윷 시퀀스에 대해 모델 선공과
후공을 모두 실행하는 deterministic paired 5,000게임이다.

| 시드 | 전체 | 선공 | 후공 | 95% Wilson | 판정 |
| ---: | ---: | ---: | ---: | --- | --- |
| 0 | 60.76% | 61.28% | 60.24% | 59.40%-62.10% | 통과 |
| 1 | 60.32% | 60.36% | 60.28% | 58.96%-61.67% | 통과 |
| 2 | 61.08% | 62.56% | 59.60% | 59.72%-62.42% | 통과 |
| 합산 | 60.72% | 61.40% | 60.04% | 59.94%-61.50% | 통과 |

세 시드 간 표준편차는 약 `0.31%p`, 범위는 `0.76%p`로 작다. 선공은 합산
`61.40%`, 후공은 `60.04%`로 선공 우위가 `1.36%p` 관찰됐다.

주의할 점은 각 개별 모델의 5,000게임 신뢰구간 하한이 모두 60% 아래라는
것이다. "point estimate 60% 통과"와 "95% 신뢰로 60% 초과"는 구분해야 한다.

## 6. 40M 대 50M 체크포인트

### 6.1 선별용 스윕

별도 base seed `200000-200499`로 각 checkpoint를 시드당 1,000게임,
합산 3,000게임 평가했다.

| checkpoint | 합산 승률 |
| ---: | ---: |
| 5M | 55.90% |
| 10M | 57.87% |
| 15M | 60.10% |
| 20M | 60.20% |
| 25M | 61.10% |
| 30M | 60.03% |
| 35M | 61.10% |
| 40M | 63.33% |
| 45M | 60.93% |
| 50M | 62.53% |

40M이 50M보다 `0.80%p` 높았지만 3,000게임 표본에서 이 정도 차이는
평가 노이즈 범위다. 실제로 seed 2는 이 스윕에서 40M이 50M보다
`2.6%p` 높았지만 다음 독립 평가에서는 방향이 반대로 바뀌었다.

### 6.2 독립 홀드아웃

선별에 쓰지 않은 base seed `300000-302499`로 40M과 최종 50M을 각각
시드당 5,000게임 비교했다.

| 시드 | 40M | 최종 50M | 50M 변화 |
| ---: | ---: | ---: | ---: |
| 0 | 60.32% | 60.98% | +0.66%p |
| 1 | 60.36% | 59.34% | -1.02%p |
| 2 | 59.94% | 62.04% | +2.10%p |
| 합산 | 60.21% | 60.79% | +0.58%p |

합산 95% 구간은 40M `59.42%-60.99%`, 50M `60.00%-61.57%`다. 구간이
크게 겹치므로 50M의 우위를 통계적으로 강하게 주장할 수는 없지만,
최종 모델이 열화됐다는 증거도 없다. 현재 선택은 최종 50M이 합리적이다.

## 8. 뒷도 규칙 작동 지표

학습 5,801,253게임에서 양쪽 플레이어를 합친 카운터는 다음과 같다.

| 지표 | 횟수 | 게임당/비율 |
| --- | ---: | ---: |
| 뒷도 등장 | 11,369,312 | 1.960/game |
| 뒷도 행동 | 9,733,580 | 1.678/game |
| 등장 대비 사용 | - | 85.61% |
| 뒷도 잡기 | 1,783,405 | 행동의 18.32% |
| 잡힌 말 | 2,141,191 | 잡기당 1.20개 |
| `O1 -> HOME` | 1,300,626 | 0.224/game |
| `HOME -> 이전 칸` | 309,092 | 0.053/game |
| legal action 없음 auto-pass | 1,499,029 | 0.258/game |

따라서 요청한 핵심 규칙은 실제 rollout에서 충분히 발생했다.

- 첫 칸에서 뒷도로 HOME 진입
- HOME에서 뒷도 사용
- 뒷도 잡기와 stack 잡기
- 뒷도만 있고 움직일 말이 없을 때 자동 패스

공식 15,000게임에서도 `O1 -> HOME` 3,354회, `HOME -> 이전 칸` 813회,
뒷도 잡기 4,280회가 기록됐다.

단, 이 카운터는 한 게임에서 PPO와 rule-based 상대의 행동을 합친 값이다.
따라서 "PPO가 뒷도를 85.61% 선택했다"는 식으로 해석하면 안 된다.
PPO 전용 전략 분석이 필요하면 player별 카운터를 추가해야 한다.

## 9. 이전 40M 모델과의 관계

보관된 기존 40M 모델의 공식 합산 승률은 `59.76%`였고 새 50M은
`60.72%`로 수치상 `+0.96%p`다.

하지만 기존 모델은 `full_backdo_v1` 이전의 20-action 환경이며 observation,
규칙, 상대 agent 동작도 다르다. 따라서 이 차이는 제어된 성능 개선 비교가
아니며, 뒷도 규칙 도입 효과나 10M 추가 학습 효과로 귀속할 수 없다.

이번 학습 내부에서의 40M 대 50M 홀드아웃 비교가 더 유효한 근거다.

남은 위험:

   재현할 수 없다.
2. 학습 중 평가는 꺼져 있어 checkpoint 선택은 사후 분석이다.

   분리할 수 없다.
4. seed 1은 독립 홀드아웃에서 59.34%로 떨어져 모델 간 품질 차이가 완전히
   사라진 것은 아니다.
