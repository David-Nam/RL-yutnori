# 윷놀이 RL 아이디어 제안

## 배경: 선행 연구

송승규 외 (2024, KIIE) 논문의 접근 방식:
- 카테고리: Value-based RL
- 가치 함수: State Value V(s) 학습 (단일 스칼라 값)
- 학습: TD Learning + Target Network
- 데이터: Self-play
- 추론: One-step Look-ahead

아래 2가지 아이디어는 모두 이 논문과 명확히 다른 방향이다.

---

## 아이디어 1: PPO로 정책을 직접 학습

### 핵심 아이디어

가치 함수를 학습한 뒤 거기서 정책을 끌어내는(greedy) 방식 대신, **정책 자체를 신경망으로 모델링해서 직접 학습**한다.

### 논문과의 차이

| 항목 | 송승규 논문 | 우리 (PPO) |
|------|-------------|------------|
| 학습 대상 | V(s) 가치 함수 | π(a\|s) 정책 함수 |
| 정책 형태 | Deterministic greedy | Stochastic |
| 학습 방식 | TD Learning | Policy Gradient + Clipped Objective |
| 신경망 출력 | 1개 스칼라 (가치) | 액션별 확률 분포 |

### 왜 윷놀이에 적합한가

- 윷놀이는 운이 많이 작용하는 게임 → 확률적 정책이 잘 맞을 수 있음
- 같은 상태에서도 가끔 다른 액션을 시도하는 것이 학습 효율 향상에 도움
- PPO는 학습 안정성이 좋아 self-play에서 정책이 발산하는 문제를 막아줌

### 구현 방식

- 네트워크 구조: 정책 헤드(action 확률) + 가치 헤드(상태 가치) 공유 신경망
- Clipped Surrogate Objective로 정책 업데이트 (PPO 핵심)
- Action masking으로 불법 액션 처리
- Self-play로 데이터 생성 (논문과 동일)

### 구현 부담

중간 수준. Stable Baselines3 라이브러리 활용하면 골격은 빠르게 잡을 수 있고, 윷놀이 환경만 잘 정의하면 됨.

### 비교 실험 거리

- 논문 방식(가치 기반)과 직접 승률 비교
- Stochastic vs Deterministic 정책의 차이 분석
- 학습 곡선 비교 (수렴 속도, 안정성)

## 아이디어 2: Categorical DQN (C51)로 가치의 분포를 학습

### 핵심 아이디어

가치의 기댓값(평균) 하나만 학습하는 대신, **가치의 전체 분포를 학습**한다. 즉 "이 상태에서 이길 확률"을 분포 형태로 표현.

### 논문과의 차이

| 항목 | 송승규 논문 | 우리 (C51) |
|------|-------------|------------|
| 학습 대상 | V(s) 기댓값 | Q(s,a)의 분포 |
| 출력 차원 | 1개 (평균값) | N개 (분포의 카테고리, 보통 51개) |
| Loss | MSE | KL Divergence |
| 정보량 | 평균만 | 분포 전체 (평균 + 분산 + 모양) |

### 왜 윷놀이에 적합한가

- 윷놀이는 확률성이 매우 큰 게임 (윷 던지기 결과가 랜덤)
- 같은 평균 가치를 가진 두 상태가 분산이 완전히 다를 수 있음
  - 예: 평균 50% 승률이지만 "안정적인 50%" vs "도박적인 50%"
- 평균만 학습하면 이 차이를 놓침 → 분포 학습으로 더 풍부한 정보 활용
- 추가로, Action Value Q(s,a)를 학습하므로 논문의 V(s)와도 차별화

### 구현 방식

- 신경망 출력을 51개의 atom으로 (보통 v_min=-1, v_max=1 사이를 51등분)
- 각 atom은 해당 가치를 가질 확률을 의미
- Distributional Bellman Operator로 target 분포 계산
- KL Divergence로 loss 계산
- Self-play로 데이터 생성

### 구현 부담

중상. 기본 DQN 구조를 알면 output 부분만 분포로 바꾸는 것이라 큰 부담은 아님. 다만 Distributional Bellman 부분은 처음 보면 헷갈릴 수 있어 참고 코드(예: CleanRL의 C51 구현) 활용 권장.

### 비교 실험 거리

- 논문 방식(기댓값 학습)과 직접 승률 비교
- 학습된 분포가 실제 게임 결과와 얼마나 일치하는지 (calibration 분석)
- "분산이 큰 상태에서 RL이 어떤 선택을 하는가" 정성 분석 (위험 회피적인지, 도박적인지)

## 둘 중 어느 쪽이 더 좋은가

| 비교 항목 | 아이디어 1 (PPO) | 아이디어 2 (C51) |
|-----------|------------------|--------------------|
| 논문과 차별화 | 학습 패러다임 자체가 다름 | 가치 표현 방식이 다름 |
| 구현 난이도 | 중 | 중상 |
| 학습 자료 풍부함 | 매우 풍부 | 풍부 |
| 윷놀이 특성과의 적합성 | 확률적 정책 측면 | 확률적 환경 측면 |
| 분석 거리 | 정책 형태 분석 | 분포 자체 분석 |

회의에서 둘 중 하나 골라서 한 명이 맡거나, 우리가 알고리즘 2개 비교할거면 둘 다 채택하는 것도 가능하다.
